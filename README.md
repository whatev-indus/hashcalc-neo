A retro-futuristic homage to the classic SlavaSoft app HashCalc.

## Features

- Calculate common file hashes, including CRC32, MD5, SHA-1, SHA-2, SHA-3, BLAKE2, BLAKE3, RIPEMD-160, and Whirlpool.
- Show file name and size alongside selected hash values.
- Drag and drop files onto the hash table, or select files with the system file picker.
- Compare a secondary file against the primary file and show whether the hashes match.
- Toggle visible hash rows in Settings.
- Switch between Neo, Modern Light, Modern Dark, and Classic themes.
- Copy calculated hash values with one click.
